## 二、模块化体系（ESM / CJS / AMD）

### **11. CommonJS 和 ES Module 区别

| **特性**       | **CommonJS** | **ES Module** |
| ------------ | ------------ | ------------- |
| 导入方式         | require()    | import/export |
| 加载机制         | 运行时加载        | 编译时静态分析       |
| 导出值          | 拷贝值          | 引用绑定          |
| 执行时机         | 同步（Node）     | 异步（浏览器）       |
| Tree-shaking | ❌ 不支持        | ✅ 支持          |
### **12. Babel 

- 语法转换（ES6 → ES5）；
- 支持新特性 polyfill（core-js/regenerator）；
- 模块转换（ESM → CJS）；
- React JSX 编译；
- 插件机制灵活。

### 13 Polyfill 与 Babel 的区别

- Babel：语法层面转换；
- Polyfill：填补运行时环境缺失的 API（Promise、Map）。
## **三、前端性能与资源优化**

### **14.前端性能优化常见指标**

| **指标** | **含义**                           |
| ------ | -------------------------------- |
| FCP    | 首次内容绘制（First Contentful Paint）   |
| LCP    | 最大内容绘制（Largest Contentful Paint） |
| CLS    | 累积布局偏移（Cumulative Layout Shift）  |
| TTI    | 可交互时间（Time To Interactive）       |
| TBT    | 阻塞时间（Total Blocking Time）        |
### **16 优化手段分类**

**构建期：**

- 压缩代码（Terser、CSSNano）
- Tree-shaking、代码分割、懒加载
- 资源哈希缓存

**运行期：**

- 图片懒加载、预加载 preload/prefetch
- Service Worker 缓存
- CDN 加速
- 长列表虚拟化
- Web Worker 分线程

### **17 懒加载与预加载区别？**

|**特性**|**懒加载**|**预加载**|
|---|---|---|
|触发时机|按需（进入视口）|提前加载未来资源|
|实现方式|IntersectionObserver / import()|<link rel="preload"> / prefetch|

### **18代码分割 (Code Splitting)**

**实现方式：**

```

import('./Component').then(...)

```

Webpack 自动分包；
或手动配置 optimization.splitChunks。

### **19 SourceMap 原理？**

保存「编译后代码 ↔ 源码」的映射关系；

开发调试使用；

生产环境可上传至 Sentry 方便错误追踪。

---

### 20. Web Worker 

将 JS 运算放入独立线程，防止阻塞 UI。

典型用途：图片压缩、大文件解析、复杂计算。

## **四、质量与 CI/CD**

### **21 前端如何保证代码质量？**
- ESLint + Prettier；
- TypeScript；
- 单元测试（Jest / Vitest）；
- E2E 测试（Cypress / Playwright）；
- Git hook（lint-staged、husky）。
### **22️⃣ Git Hook 有什么用？**

  

自动化质量管控：

- commit 前 lint；
    
- push 前测试；
    
- commit-msg 校验（如 Conventional Commits）。
    

---

### **23️⃣ CI/CD 流程怎么做？**

  

1️⃣ Push 到主分支触发 CI（GitHub Actions、GitLab CI）。

2️⃣ 自动执行测试、lint、build。

3️⃣ 构建产物上传 OSS/CDN。

4️⃣ 触发部署（Docker/K8s/Nginx 更新）。

---

### **24️⃣ 如何做自动化部署？**

- 使用 GitHub Actions 或 Jenkins；
- 监听 main 分支；
- 执行：

```

npm ci
npm run build
rsync dist/ server:/www/

```

- 可结合 Docker 镜像打包 + k8s rollout。

### **25Docker 在前端中的应用？**

- 构建统一环境（Node 版本、依赖）；
- 部署静态资源镜像；
- CI/CD 流水线中自动构建镜像；
- 容器化多环境（dev/staging/prod）。

## **五、安全与监控体系**

### **28 如何监控前端错误与性能？**

- 全局 window.onerror、unhandledrejection；
- 资源加载失败（addEventListener ‘error’）；
- Performance API（LCP、FCP、CLS）；
- 上报到监控系统（Sentry、阿里 ARMS、Grafana Faro）。
### **29 如何防止打包体积过大**

- 使用 webpack-bundle-analyzer；
- 拆分 vendor 依赖；
- 按需加载（React.lazy / Vue 异步组件）；
- 去除 moment locale；
- gzip / brotli 压缩；
- 使用 CDN。

### **30.前端环境区分与配置管理**

- 使用 .env.[mode] 文件；
- 通过 process.env.NODE_ENV 控制分支；
- 构建时替换环境变量；
- 区分 dev/staging/prod 三环境。

## **六、面试追问方向（延伸提问）**

| **面试官问题**            | **追问角度**                                     |
| -------------------- | -------------------------------------------- |
| 为什么要做工程化？            | 提高开发效率、性能、可维护性、质量一致性。                        |
| Vite 为什么更快？          | ESM + ESBuild 预构建 + 即时编译。                    |
| Tree-shaking 为什么不生效？ | 模块有副作用 / 使用 CJS / 未设置 sideEffects: false。    |
| 如何减少首屏加载时间？          | 分包、懒加载、预渲染、SSR。                              |
| 如何处理多环境构建？           | 环境变量注入 + dotenv + mode 区分。                   |
| 如何分析打包性能？            | webpack-bundle-analyzer、source-map-explorer。 |
| 怎样提升团队工程质量？          | 规范化（ESLint、Prettier、Commit lint）、测试、CI/CD。   |
| 你会怎么设计一个前端工程脚手架？     | 模板初始化 + 配置生成 + 插件机制 + CLI。                   |
