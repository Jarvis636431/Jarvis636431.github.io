##### Vite分页面打包的操作

##### **1. 多页应用目录结构（推荐）**

```

project/
├── src/
│   ├── pages/
│   │   ├── home/
│   │   │    ├── index.html
│   │   │    └── main.js
│   │   ├── admin/
│   │   │    ├── index.html
│   │   │    └── main.js
│   │   └── about/
│   │        ├── index.html
│   │        └── main.js
├── vite.config.js
└── package.json

```

每一个页面都是独立入口（一个 HTML + 一个 main.js）。
##### ** 2. Vite 多页应用最核心配置**
在 vite.config.js 中：

```javascript
import { defineConfig } from 'vite'
import { resolve } from 'path'

export default defineConfig({
  build: {
    rollupOptions: {
      input: {
        home: resolve(__dirname, 'src/pages/home/index.html'),
        admin: resolve(__dirname, 'src/pages/admin/index.html'),
        about: resolve(__dirname, 'src/pages/about/index.html')
      }
    }
  }
})

```

说明：
- input 字段告诉 Rollup：这些 HTML 是打包入口
- 打包后会生成多个 HTML：

```

dist/
├── home.html
├── admin.html
└── about.html

```

##### **3. Vite 多页开发模式（自动识别入口）**
开发环境下：

```shell
npm run dev

```

Vite 会自动识别多个 HTML，访问：

```

http://localhost:5173/src/pages/home/index.html
http://localhost:5173/src/pages/admin/index.html
http://localhost:5173/src/pages/about/index.html

```

你也可以配置 root，使 URL 更友好：

```javascript
export default defineConfig({
  root: 'src/pages/'
})

```

但不推荐，不够灵活。
##### **4. 打包后目录结构（示例）**

```

dist/
├── assets/
│   ├── home-xxxx.js
│   ├── admin-xxxx.js
│   ├── about-xxxx.js
└── home.html
└── admin.html
└── about.html

```

所有页面共享 assets/ 静态资源。
##### **5. 不同页面引用不同 JS**
HTML 内这样写：

```html
<script> type="module" src="./main.js"></script>

```

Vite 会自动做路径处理和 hash。
##### **6. 如果入口特别多（几十个页面）**
你可以自动扫描目录：

```javascript
import fs from 'fs'
import path from 'path'

function getPages(dir) {
  const pages = {}
  const pageDirs = fs.readdirSync(dir)

  pageDirs.forEach(p => {
    const full = path.join(dir, p, 'index.html')
    if (fs.existsSync(full)) {
      pages[p] = full
    }
  })

  return pages
}

export default defineConfig({
  build: {
    rollupOptions: {
      input: getPages('./src/pages')
    }
  }
})

```

##### ** 7. 多页共享公共组件**
像 React/Vue 组件可以全项目共用：

```

src/components/

```

不影响多页应用
##### **8. 常见坑 & 解决方案**

###### **问题 1：打包后每个页面路径引用错了**
解决：使用绝对路径，不要写：

```html
<script src="main.js"></script>

```

应该写：

```html
<script type="module" src="/src/pages/home/main.js"></script>

```

或者保持相对路径，但要确保结构一致。
###### **问题 2：静态资源加载路径不对**

配置 base：

```javascript
export default defineConfig({
  base: './'
})

```

适合部署到 **非根路径**（如 GitHub Pages）。
###### **问题 3：多个页面需要注入不同环境变量**
你可以用：

```

.env.home
.env.admin
.env.about

```

并在启动时：

```

vite build --mode home

```
