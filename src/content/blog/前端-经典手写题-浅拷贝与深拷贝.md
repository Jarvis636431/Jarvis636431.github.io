## 一、什么是浅拷贝？

**浅拷贝：只拷贝一层，如果遇到对象/数组等引用类型，只复制引用，不复制内容。**
## **举例：**

```javascript
const obj = { a: 1, b: { c: 2 } };
const clone = { ...obj };

clone.b.c = 99;

console.log(obj.b.c); // 99（被改了）

```

原因：

clone.b 和 obj.b 指向的是同一个对象。
## **常见浅拷贝方式：**

| **方法**                   |
| ------------------------ |
| {...obj}                 |
| Object.assign({}, obj)   |
| Array.prototype.slice()  |
| Array.prototype.concat() |
| [].map, [...arr]         |

## 二、什么是深拷贝？

**深拷贝：所有层级全部复制，不共享引用。**
## **举例：**

```javascript
const obj = { a: 1, b: { c: 2 } };
const clone = deepClone(obj);

clone.b.c = 99;

console.log(obj.b.c); // 2（不变）

```

深拷贝让两个对象互相独立。
## 三、常见深拷贝的方式

## **方式 1：JSON.parse(JSON.stringify())**

### **优点**
- 简单
- 能应对大部分普通对象  
### **缺点**
不能拷贝：
- **函数**
- **undefined**
- **Symbol**
- **正则表达式 RegExp**
- **Date**
- **Map / Set**
- **循环引用（会报错）**
  
例如：

```javascript
JSON.parse(JSON.stringify({ a: undefined })) // { }

```

## **方式 2：递归深拷贝**

```javascript
function deepClone(obj) {
  if (obj === null || typeof obj !== "object") return obj;

  const result = Array.isArray(obj) ? [] : {};

  for (let key in obj) {
    result[key] = deepClone(obj[key]);
  }

  return result;
}

```

### **能处理：**
- 普通对象
- 数组
- 嵌套结构
### **不能处理：**
- 循环引用
- Date / RegExp / Map / Set
- Symbol 作为 key
## **方式 3：能处理循环引用的深拷贝（高级手写题）**

使用 WeakMap 记录已拷贝过的对象。

```javascript
function deepClone(obj, map = new WeakMap()) {
  if (obj === null || typeof obj !== "object") return obj;

  if (map.has(obj)) return map.get(obj);

  let cloneObj = Array.isArray(obj) ? [] : {};
  map.set(obj, cloneObj);

  for (let key in obj) {
    cloneObj[key] = deepClone(obj[key], map);
  }

  return cloneObj;
}

```

### 能处理：
- 循环引用
- 嵌套结构
### **不能处理正则、Date、Map、Set（需要扩展）**

## 方式 4：完全版深拷贝（能处理 99% 情况）

如果你要写一个“真正的深拷贝”，必须判断不同类型：

- Date
- RegExp
- Map
- Set
- Array
- Object
- Symbol
- Function（通常直接返回原函数）
### **✨ 完整版示例（中高难度）：**

```javascript
function deepClone(obj, map = new WeakMap()) {
  if (obj === null || typeof obj !== "object") return obj;

  if (map.has(obj)) return map.get(obj);

  let clone;

  // Date
  if (obj instanceof Date) {
    clone = new Date(obj);
  }
  // RegExp
  else if (obj instanceof RegExp) {
    clone = new RegExp(obj.source, obj.flags);
  }
  // Map
  else if (obj instanceof Map) {
    clone = new Map();
    map.set(obj, clone);
    obj.forEach((v, k) => clone.set(deepClone(k, map), deepClone(v, map)));
  }
  // Set
  else if (obj instanceof Set) {
    clone = new Set();
    map.set(obj, clone);
    obj.forEach(v => clone.add(deepClone(v, map)));
  }
  // Array or Object
  else {
    clone = Array.isArray(obj) ? [] : {};
    map.set(obj, clone);
    for (const key in obj) {
      clone[key] = deepClone(obj[key], map);
    }
  }

  return clone;
}

```

## 四、深拷贝追问

## **1. 为什么 JSON.parse(JSON.stringify()) 不能深拷贝 Date？**

因为 JSON 会把日期序列化为字符串：

```javascript
JSON.stringify({ time: new Date() })
// => { "time": "2025-11-22T08:00:00.000Z" }

```

解析回来就不是 Date 类型了。
## **2. 什么情况下必须深拷贝，而不是浅拷贝？**

举例：

- Redux reducer 返回新的 state（否则会破坏不可变数据）
- Vue3 reactive → 不允许改原对象引用
- React 组件 shouldComponentUpdate / memo 比较  

比如 Redux：

```javascript
return {
  ...state,
  list: [...state.list, newItem]
};

```

如果你浅拷贝 state，但内部引用没变，会导致 diff 误判。

## **3. 深拷贝会有什么性能问题？**

- 性能开销大（递归 + 对象创建）
- 嵌套对象过深会造成栈溢出（Stack Overflow）
- 若滥用深拷贝会导致渲染卡顿

这是为什么 React/Vue 推荐**不可变数据 + 浅比较 + 局部更新**。
