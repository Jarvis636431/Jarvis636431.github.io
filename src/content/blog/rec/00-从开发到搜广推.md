我想从开发转向搜广推算法方向。

这不是一份试图一次解决所有问题的完美路线图，而是一份持续更新的实践记录。我会记录学到的概念、完成的实验、遇到的问题和对实际业务的理解，最终形成一套可以展示的作品集。

## 阶段性目标

我把腾讯广告算法大赛作为这次转型的第一个里程碑。

现阶段不同时铺开搜索、推荐和广告的所有方向，而是先聚焦于：

> 推荐与广告排序，尤其是 CTR、CVR 预估和用户行为序列建模。

## 学习主线

1. 补齐数学、机器学习和深度学习基础。
2. 理解推荐系统的召回、粗排、精排和重排链路。
3. 掌握 CTR/CVR 预估中的特征工程与经典模型。
4. 学习用户行为序列、特征交互和多任务学习。
5. 完成可复现的实验，建立可靠的离线评估流程。
6. 参加比赛，将方法、代码、结果和复盘整理为作品。

## 时间规划

以每周投入 8～10 小时为基准：

- **8～12 周**：建立完整基础，能够阅读经典论文并复现基础模型。
- **4～6 个月**：形成较完整的搜广推知识体系，完成一个有说服力的端到端项目。
- **6 个月以上**：进入比赛实战、前沿论文和求职专项阶段。

这些时间是节奏参考，实际进度以阶段成果为准，不以“听完了多少课”作为掌握标准。

## 课程表

整个基础课程分为八个模块，学习链路为：

```text
数据 → 特征 → 模型 → 损失 → 评估 → 实验 → 系统 → 论文
```

### 阶段一：CTR 预估基础

**预计时间：1～2 周**

- [x] 搜广推整体链路与多级漏斗。
- [x] 曝光、点击、转化与数据链路。
- [x] CTR、CVR、CTCVR 与常见业务指标。
- [x] LR、Sigmoid、BCE 与梯度下降原理。
- [x] 实现一个 LR CTR 模型。
- [x] 学习 AUC、LogLoss、概率校准和评估方法。
- [ ] 理解类别不平衡、负采样和样本权重。
- [ ] 理解过拟合、正则化与数据集划分。

**阶段成果：**能用 PyTorch 实现 LR，构造模拟曝光数据，训练并输出 pCTR，使用 AUC 和 LogLoss 评估并解释结果。

### 阶段二：稀疏特征与特征交互

**预计时间：2 周**

- One-Hot、Embedding 与高维稀疏特征。
- 特征交叉的意义与 LR 的能力边界。
- Factorization Machine（FM）。
- Wide & Deep、DeepFM 与 DCN。
- 模型对比和消融实验。

**阶段成果：**实现并比较 LR、FM 和 DeepFM，记录 AUC、LogLoss、参数量与训练时间。

### 阶段三：召回系统

**预计时间：2 周**

- 隐式反馈与推荐数据。
- UserCF、ItemCF 和矩阵分解。
- 双塔模型与负采样。
- 向量相似度、Top-K 与 ANN。
- Recall@K、Hit Rate 和 NDCG。

**阶段成果：**构建“用户行为 → 双塔向量 → 向量检索 → Top-K 候选”的最小召回系统。

### 阶段四：用户兴趣与序列建模

**预计时间：2～3 周**

- 用户行为序列和兴趣漂移。
- Attention 的基本原理。
- DIN 的候选相关兴趣建模。
- DIEN 的兴趣演化建模。
- RNN、GRU、Transformer 和 SASRec 等序列推荐方法。

**阶段成果：**实现 DIN 或简化的 Transformer 序列推荐模型，并与 DeepFM 比较。

### 阶段五：CVR 与多任务学习

**预计时间：1～2 周**

- CVR 的样本选择偏差。
- 延迟反馈与转化归因。
- ESMM 的全空间多任务建模。
- MMoE 与多目标学习。
- CTR、CVR 和 CTCVR 的联合建模。

**阶段成果：**能解释并实现简化 ESMM，理解广告排序中多任务学习的动机。

### 阶段六：搜索与 Learning to Rank

**预计时间：1～2 周**

- Query、文档与相关性。
- 倒排索引、词项检索与 BM25。
- Pointwise、Pairwise 和 Listwise 排序。
- RankNet、LambdaRank 与 LambdaMART。
- 搜索语义召回与双塔。

**阶段成果：**实现最小文本召回与重排流程，能解释 CTR 二分类与 Learning to Rank 的区别。

### 阶段七：工业系统与实验方法

**预计时间：2 周**

- 离线与在线特征一致性。
- 数据泄漏、数据穿越与时间切分。
- A/B 测试与显著性。
- 离线指标与线上指标不一致。
- 模型校准、冷启动、曝光偏差和位置偏差。
- 模型服务的延迟、吞吐与可靠性。

**阶段成果：**看到指标提升时，能系统检查数据口径、切分方式、泄漏、校准、实验显著性和服务成本。

### 阶段八：论文阅读与完整项目

**预计时间：与前面阶段交叉进行，并持续投入**

经典模型的建议阅读顺序：

```text
LR → FM → Wide & Deep → DeepFM → DIN → DIEN
   → DSSM/双塔 → SASRec → ESMM → MMoE
```

每篇论文需要回答：

1. 论文在解决什么问题？
2. 以前的方法为什么不够？
3. 输入、模型结构、输出和损失函数是什么？
4. 实验基线和评估方法是否合理？
5. 效果提升来自哪个模块？
6. 它的局限和线上部署问题是什么？
7. 能否实现一个最小可复现版本？

**阶段成果：**用公开行为数据完成“数据与样本 → 双塔召回 → LR/FM/DeepFM 精排 → 序列兴趣增强 → 离线评估 → 推理服务 → 技术报告”的端到端项目。

## 基础阶段的验收标准

当我可以完成下列任务时，才认为基础体系已经成形：

- 独立解释召回、粗排、精排和重排。
- 能够从日志中定义样本、特征和标签。
- 能够实现 LR、FM、DeepFM 和双塔模型。
- 理解 Embedding、Attention 和序列建模。
- 能使用 AUC、LogLoss、Recall@K 和 NDCG 评估模型。
- 能识别数据泄漏、样本偏差和类别不平衡。
- 能阅读经典论文，绘制模型结构并实现最小版本。
- 能设计基线、对比实验和消融实验，并解释结果。
- 讨论模型时不仅能说明“它是什么”，还能讨论“为什么这样设计”。

完成前五个阶段后，学习方式应当从单向讲解逐渐转为双向讨论；完成前七个阶段后，则应具备较独立的经典论文阅读和实验能力。
