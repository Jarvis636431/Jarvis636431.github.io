Logistic Regression（逻辑回归，LR）是最经典的 CTR 预估模型之一。它的结构很简单，却包含了现代模型训练的基本元素：特征、参数、前向传播、损失函数、反向传播和优化器。

先记住它的最小结构：

```text
特征 x
  ↓
线性打分 z = wᵀx + b
  ↓
Sigmoid
  ↓
点击概率 p
```

## 1. LR 是什么，又不是什么

LR 是可训练的线性二分类模型。它可以使用前向传播、反向传播和梯度下降，但通常不被称为深度学习模型，因为它没有多层隐藏层和逐层表示学习。

```text
LR：x → Linear → Sigmoid

深度 CTR 模型：
x → Embedding → 多层特征交互 → Linear → Sigmoid
```

反向传播是计算梯度的通用方法，不是深度学习独有标志。

## 2. 输入：把业务事件变成特征向量

一条 CTR 样本可能包含：

```text
用户年龄：25
城市：上海
用户兴趣：篮球
广告类别：运动鞋
价格：500
展示位置：2
时间段：晚上
是否点击：1
```

模型不能直接理解“上海”和“运动鞋”，需要把原始数据编码为数值。

### 2.1 连续特征

年龄、价格和历史点击次数等数值可以进行标准化、归一化、取对数或分桶，避免数值尺度相差过大。

```text
标准化：x' = (x - 均值) / 标准差
长尾数值：x' = log(1 + x)
```

### 2.2 类别特征

城市、设备、用户 ID 和商品 ID 可以使用 One-Hot 或其他稀疏编码：

```text
城市_北京 = 0
城市_上海 = 1
城市_深圳 = 0
```

真实 CTR 系统可能有百万维以上的特征空间，但一条样本中只有少量位置非零，这就是高维稀疏特征。

## 3. 线性层：每个特征为结果加分或减分

LR 为每个输入特征学习一个权重：

```text
z = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
```

简写为：

```text
z = wᵀx + b
```

其中：

- `x` 是样本特征；
- `w` 是需要学习的权重向量；
- `b` 是偏置；
- `z` 是没有限定范围的线性分数，也叫 logit。

在其他特征不变的情况下，权重为正值的特征会提高 `z`，权重为负值的特征会降低 `z`。但权重表示数据中的统计相关，不能直接解释为因果关系。

## 4. Sigmoid 为什么会出现

线性分数 `z` 可以从负无穷到正无穷，而概率必须位于 `0～1`。Sigmoid 提供了这个映射：

```text
p = σ(z) = 1 / (1 + e⁻ᶻ)
```

| z | p = sigmoid(z) |
| ---: | ---: |
| -5 | 约 0.7% |
| -2 | 约 11.9% |
| 0 | 50% |
| 2 | 约 88.1% |
| 5 | 约 99.3% |

Sigmoid 不只是因为它的输出像概率，它还能从对数几率的建模假设中推导出来。

### 4.1 概率、几率与对数几率

事件发生的概率是 `p`，不发生的概率是 `1-p`。几率定义为：

```text
odds = p / (1-p)
```

对几率取对数：

```text
logit(p) = log[p/(1-p)]
```

概率的范围是 `0～1`，对数几率的范围则是整个实数轴。LR 的核心假设是：

> 事件发生的对数几率，是输入特征的线性函数。

```text
log[p/(1-p)] = wᵀx + b = z
```

对上式整理：

```text
p/(1-p) = eᶻ
p = eᶻ/(1+eᶻ)
p = 1/(1+e⁻ᶻ)
```

这就是 Sigmoid。因此它来自明确的概率建模假设，不是随意选出的曲线。

## 5. 二元交叉熵为什么会出现

点击标签只有两个值：

```text
y = 1：点击
y = 0：未点击
```

可以把每次曝光是否点击看作伯努利随机变量：

```text
P(y=1) = p
P(y=0) = 1-p
```

将两种情况合并：

```text
P(y | x) = pʸ(1-p)¹⁻ʸ
```

当 `y=1` 时，结果是 `p`；当 `y=0` 时，结果是 `1-p`。

训练希望模型尽可能高概率地解释已经观察到的数据，即最大化所有样本的似然：

```text
Likelihood = ∏ pᵢʸⁱ(1-pᵢ)¹⁻ʸⁱ
```

取对数后，连乘变成连加：

```text
Log Likelihood
= Σ [yᵢlog(pᵢ) + (1-yᵢ)log(1-pᵢ)]
```

最大化对数似然，等价于最小化它的负数：

```text
Loss
= -Σ [yᵢlog(pᵢ) + (1-yᵢ)log(1-pᵢ)]
```

这就是 Binary Cross Entropy（二元交叉熵，BCE），也是伯努利模型的负对数似然。

## 6. 交叉熵如何惩罚错误

对于正样本 `y=1`：

```text
Loss = -log(p)
```

对于负样本 `y=0`：

```text
Loss = -log(1-p)
```

| 真实标签 | 预测概率 | 结果 |
| ---: | ---: | --- |
| 1 | 0.99 | 损失很小 |
| 1 | 0.01 | 损失很大 |
| 0 | 0.01 | 损失很小 |
| 0 | 0.99 | 损失很大 |

交叉熵会强烈惩罚“对错误答案过度自信”的模型。

## 7. 为什么不优先使用均方误差

均方误差是：

```text
MSE = (p-y)²
```

它不是完全不能用，但它更自然地对应连续值和高斯噪声假设。点击是 `0/1` 伯努利事件，BCE 与数据生成模型更匹配。

另外，Sigmoid 和 BCE 组合后，对 logit `z` 的梯度非常简洁：

```text
∂Loss/∂z = p-y
```

当正样本被错误预测为 `p=0.01` 时：

```text
p-y = 0.01-1 = -0.99
```

模型会得到很明显的修正信号；当预测已经很准确时，梯度自然变小。

## 8. LR 的反向传播

对一条样本：

```text
z = wᵀx + b
p = sigmoid(z)
Loss = BCE(p, y)
```

通过链式法则可得：

```text
∂Loss/∂z = p-y
∂Loss/∂w = (p-y)x
∂Loss/∂b = p-y
```

假设正样本的真实标签是 `y=1`，模型只预测 `p=0.2`：

```text
p-y = -0.8
```

相关特征的梯度是负值。使用梯度下降更新：

```text
w_new = w_old - 学习率 × 梯度
```

减去负数会使相关权重增大，下次遇到类似特征时，`z` 和点击概率都会上升。

如果负样本 `y=0` 却被预测为 `p=0.8`，梯度为正，相关权重会降低。

## 9. 反向传播与梯度下降的区别

```text
反向传播：通过链式法则计算每个参数的梯度
梯度下降：使用梯度更新参数
```

它们回答两个不同问题：

- 反向传播：参数应该往哪里调？
- 优化器：知道方向后，具体怎样走一步？

LR、FM、神经网络和 LLM 都可以用这套机制训练。

## 10. 完整训练过程

### 10.1 构造样本

从有效曝光日志中构造：

```text
用户特征 + 候选特征 + 上下文特征 → 是否点击
```

### 10.2 按时间划分数据

搜广推数据有明显的时间性，常见方式是：

```text
较早日期 → 训练集
较晚日期 → 验证集
最新日期 → 测试集
```

这更接近用过去数据预测未来的真实场景。

### 10.3 初始化参数

```text
w = 零或较小的初始值
b = 0
```

### 10.4 Mini-batch 前向传播

一次取出一小批样本：

```text
z = Xw + b
p = sigmoid(z)
```

### 10.5 计算平均损失

```text
Batch Loss = 每条样本 BCE 的平均值
```

可以加入正则化，约束权重不要无限增大：

```text
总损失 = BCE + λ‖w‖²
```

### 10.6 反向传播并更新

```text
清空旧梯度
→ 反向传播
→ 优化器更新 w 和 b
```

### 10.7 重复迭代

一次完整遍历训练集称为一个 Epoch。训练通常包含多个 Batch 和多个 Epoch。

### 10.8 验证、保存与部署

定期在验证集上计算 LogLoss、AUC 和概率校准等指标。完成训练后，保存特征编码规则、参数和模型版本。

线上预测只执行：

```text
构造特征 → 前向传播 → 输出 pCTR
```

因为线上请求当时没有真实标签，所以通常不计算损失，也不执行反向传播。

## 11. 用伪代码对应整个过程

```python
model = LogisticRegression()
optimizer = SGD(model.parameters(), learning_rate=0.01)

for epoch in range(num_epochs):
    for features, labels in train_loader:
        logits = model(features)
        loss = binary_cross_entropy_with_logits(logits, labels)

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

| 代码 | 数学意义 |
| --- | --- |
| `model(features)` | `z = wᵀx+b` |
| `binary_cross_entropy_with_logits` | 数值稳定的 Sigmoid + BCE |
| `zero_grad()` | 清空上一个 Batch 的梯度 |
| `backward()` | 通过反向传播计算梯度 |
| `step()` | 优化器更新参数 |

训练时常直接把 `logits` 交给 `BCEWithLogitsLoss`，而不是先手动计算 Sigmoid。这两步在数学上等价，合并实现可以避免概率接近 `0` 或 `1` 时的数值溢出。

## 12. LR 的能力与局限

LR 的优点是：

- 结构简单，训练和推理快；
- 适合高维稀疏特征；
- 稳定、容易部署；
- 权重具有一定可解释性；
- 是非常有价值的排序 Baseline。

它的核心局限是只能直接学习一阶线性作用：

```text
w₁x₁ + w₂x₂
```

它不会自动学习：

```text
用户喜欢篮球 × 当前内容是篮球
```

可以手工构造交叉特征，但当特征数量很大时，所有组合会迅速爆炸。这正是 FM、Wide & Deep、DeepFM 等模型要继续解决的问题。

## 13. Sigmoid + BCE 是数学还是经验

两者兼有，但首先有明确的数学依据：

```text
点击是 0/1 事件
  ↓
使用伯努利分布建模
  ↓
假设对数几率与特征线性相关
  ↓
推导出 Sigmoid
  ↓
使用最大似然估计参数
  ↓
取负对数
  ↓
推导出二元交叉熵
```

工程经验则证明了这套假设在大量真实二分类和 CTR 场景中足够稳定、高效。

它们并非唯一选择。其他任务可能使用 Probit、Hinge Loss、Focal Loss、Pairwise Loss 或 Listwise Loss。模型和损失函数的选择，需要与标签的概率假设和真正优化的目标匹配。

## 14. 一个数值例子

假设：

```text
x = [1, 0, 1]
w = [0.5, -0.4, 0.8]
b = -1
y = 1
```

前向传播：

```text
z = 1×0.5 + 0×(-0.4) + 1×0.8 - 1
  = 0.3

p = sigmoid(0.3)
  ≈ 0.574
```

模型预测点击概率约为 `57.4%`。真实标签为 `1`，因此：

```text
∂Loss/∂z = p-y
          = 0.574-1
          = -0.426
```

权重梯度：

```text
∂Loss/∂w = (p-y)x
          = -0.426 × [1, 0, 1]
          = [-0.426, 0, -0.426]
```

如果学习率为 `0.1`，两个活跃特征对应的权重都会增加 `0.0426`。下次遇到类似样本时，模型会给出更高的点击概率。

## 15. 总结

1. LR 是“线性打分 + Sigmoid”的线性二分类模型，不是深度模型。
2. `z = wᵀx+b` 产生 logit，`p = sigmoid(z)` 产生概率。
3. LR 假设对数几率 `log[p/(1-p)]` 是特征的线性函数。
4. 点击标签可以用伯努利分布建模。
5. 二元交叉熵是伯努利模型的负对数似然。
6. Sigmoid 与 BCE 组合后，有 `∂Loss/∂z = p-y`。
7. 反向传播计算梯度，优化器使用梯度更新参数。
8. 训练需要标签、损失和反向传播；线上推理通常只需要前向传播。
9. LR 快、稳定、适合稀疏特征，但不会自动学习复杂特征交互。
