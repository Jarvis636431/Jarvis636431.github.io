现在我们要开始具体编写 nginx.conf 配置文件
首先是一些基本原则：一台服务器不应该暴露所有的端口，应该只暴露 80 和 443端口，其中 80 端口是给 http 使用的，443 端口是给 https 使用的，现在为了我们所有的服务都想使用 https，我们需要把 80 端口通过 301 代理，也转发到 443 端口，既：用户访问 http://examlple.com 的时候，会先访问到 80 端口，然后再跳转到 443 端口


现在我们还需要在 443 端口的配置中，启用我们的证书，详情可见具体的配置文件内容

#### systemd

刚刚我们的运行方式是通过 ssh 链接上服务器，然后直接运行二进制程序，那么如果退出ssh，我们的后端程序也会随之退出，所以我们现在需要让他持续运行

主要有两种方法，第一个是 linux 的 screen 命令，相当于把运行这个程序的终端会话窗口独立出来在后台运行，还有就是我们现在要讲的 systemd

systemd 就是 linux 自带的一个服务，我们可以通过编写一个.service 文件，来把这个程序设置为一个系统应用，然后可以实现开机自启断掉重启等等

路径如下`/etc/systemd/system/idesignLab.service`

自此，我们的 idesignlab 后端已经部署完成了，实现了稳定的接口与 https 服务

现在我们来看前端部分，首先需要在微信公众平台上设置为开发者，然后下载微信开发者工具，拉取微信 git 上的代码，在本地运行就可以

如果需要推送新版本，就需要先把修改好的代码打包上传，然后在公众平台的后端设置对应的版本

注意，如果后续更新的话，需要先停止 systemd 服务，否则无法直接上传二进制文件，服务在执行的时候会锁住文件，无法替换

而且注意，数据库不要随意更改，不使用 root 登录，修改数据库也需要先停止 systemd 服务
